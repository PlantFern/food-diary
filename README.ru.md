# food-diary

Этот проект — бэкенд платформы «Дневник питания», которая позволяет пользователям отслеживать ежедневные приёмы пищи, потребление калорий и нутриентов, вес, процент жира и продолжительность сна.
Платформа поддерживает несколько ролей пользователей, благодаря чему тренеры, врачи и диетологи могут регистрироваться и отслеживать дневники тех пользователей, которые предоставили им доступ.

## Возможности

- Отслеживание приёмов пищи с автоматическим подсчётом калорий и нутриентов
- Запись веса, процента жира и продолжительности сна
- Доступ на основе ролей (Пользователь, Тренер, Врач, Диетолог)
- Безопасный обмен данными дневника со специалистами
- Комментарии от пользователей и специалистов
- Создание собственной еды и рецептов
- Создание шаблонов приёмов пищи
- Добавление еды и рецептов в избранное

## Технический стек

- **Язык**: Java 21
- **Фреймворк**: Spring Boot 4.1 + Spring Modulith
- **Безопасность**: Spring Security + OAuth 2.0
- **Хранение данных**: Spring Data JPA + MySQL + Flyway
- **Маппинг**: MapStruct
- **Шаблонизатор**: Thymeleaf
- **Сборка**: Maven
